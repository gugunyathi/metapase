# 3-minute demo video plan

Record with `MODEL_API_KEY` set so the store agents' Muse lines appear. Use a clean browser profile (or clear site data) so the welcome screen shows. Keep the header badge on screen: it should read **Muse Spark**.

| Time | Show | Say |
| --- | --- | --- |
| 0:00 | The welcome screen | "Shoppers never know which store would sell them what they want for less. Shops discount blindly. MetaPase gives each side an agent." |
| 0:15 | Tap **Create my agent** | "One tap. No sign-up. R1,000 welcome credit." |
| 0:25 | Deals glide in; cards leave as the agent buys or parks them | "I'm walking past stores. My agent haggles with each store's own agent, then buys inside my limit or parks the deal." |
| 0:55 | Open a deal, scroll to **Negotiation** | "Both sides are Muse Spark. Here is what the store's agent said each round." |
| 1:20 | Parked and Bag | "Bought within budget, parked when it wasn't. Nothing waits for a tap." |
| 1:35 | Discover, Manual Buy, then the store's **Merchant Hub** | "The store sees the sale, its stock dropped by one, the voucher is ready to redeem." |
| 1:55 | **Ask Muse** in the Merchant Hub | "Muse tells the store manager what to do next, using their own stock numbers." |
| 2:10 | Wishlist: say "a smart blazer for a wedding under R1500, buy it automatically" | "Muse turns a sentence into a wish. My own number wins over the model's." |
| 2:25 | Switch Watch, Car, Voice views | "Same agent on a watch, in the car, by voice." |
| 2:40 | The guardrail tests passing (`npm test`) | "Muse proposes, code decides. The store can't sell below its floor, even if the model tries." |
| 2:55 | The badge, then the open-weights line | "Switch three variables and it runs on Muse Spark Open." |

Between takes: clear the site's local storage to reset the agent, stock and sales.
